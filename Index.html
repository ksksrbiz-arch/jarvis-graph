HOW IT FITS TOGETHER

From raw data to business intuition

The Graph system is the engine beneath Jarvis's ② Brain layer. It ingests your emails, notes, calendar, code commits, and bookmarks — then maps every entity, event, and relationship into a queryable knowledge graph. Jarvis queries this graph on every reasoning cycle to make context-aware decisions without starting from scratch each time.

Ingesters
Claude Code projects, git history, markdown files, and bookmarks flow in automatically. The v2 API also accepts live paste via /api/v1/public/ingest.
Graph Layer
Entities become nodes; relationships become edges. Vector embeddings enable semantic similarity search across the entire knowledge base.
MCP Server
A built-in Model Context Protocol server (scripts/mcp-server.mjs) exposes the graph to Claude, Cursor, and any MCP client — the same interface Jarvis uses internally.
